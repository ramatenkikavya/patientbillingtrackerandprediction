# Patient Billing Tracker and Prediction

Live Demo: (add Vercel link after deployment)

A data analytics project to track hospital billing and predict outstanding payments.

### 📊 Dashboard KPIs
- **Total Billed:** 65M
- **Total Paid:** 59M
- **Total Outstanding:** 6M
- **Collection %:** 90.52%

### 📈 Visuals Used
- KPI Cards (Billed, Paid, Outstanding, Collection %)
- Pie Chart - Payment Type
- Bar Chart - Department wise Billed
- Treemap - Outstanding Risk
- Slicer - Department Filter

### 🛠 Tools
- Power BI Desktop
- Excel
- HTML/CSS (for web version)
- Vercel for deployment
